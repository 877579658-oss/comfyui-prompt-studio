# ComfyUI Prompt Studio

一个完全离线、无第三方依赖的本地提示词构建网页，面向图片和视频生成。

## 在线访问

https://877579658-oss.github.io/comfyui-prompt-studio/

## 启动

双击 `启动提示词工作台.cmd`。

网页地址：

```text
http://127.0.0.1:4317/
```

服务只监听本机回环地址，不会对局域网或互联网开放。

### 在手机 / 平板上打开（同一 Wi-Fi）

双击 `启动局域网访问.cmd`，窗口会打印类似：

```text
Prompt Studio 已开启局域网访问（同一 Wi-Fi 下的设备可用）：
  http://192.168.1.43:4317/
```

在手机的浏览器里输入这个地址即可。首次访问如果打不开，在 Windows 防火墙提示里允许 Node.js。
注意：开启局域网访问后，**同一 Wi-Fi 下的任何设备都能打开这个页面**（包括开放词库），公共场合请用回默认的单机启动方式。

## 使用方式

- **画面尺寸（像素）**：预设列表 + 自定义宽高输入，自动计算比例并同步「画面比例」；导出的 JSON 带 `size.width / size.height / size.ratio`，「完成并检查」会校验范围与 64 的倍数（SDXL / Flux 更稳）
- 顶部「一句话开始」：输入一句中文（例如“雨夜霓虹街头的女孩回头，电影感浅景深”），页面在本机匹配已有选项并预填最多 8 个字段，命中项显示为标签，点标签可单项取消，也可以一键撤销。匹配完全在本地完成，不联网
- 顶部向导按“流程 / 本步 / 状态”分三层：第一行切换七个步骤，第二行只显示当前步骤的分类，第三行显示本步检查状态
- 人物关系快捷入口已移除；人物数量与关系统一在角色设置的“关系构成”中调整
- **画面重点**：用情绪与关系、身体线条、时装与材质、氛围与叙事、动作与姿态替代笼统的“女性向 / 男性向”
- **一句话解析并补全**：按输入语言决定主提示词语言，保持当前内容尺度，锁定解析出的字段，只随机补全未锁定字段；取消后的标签可再次点击恢复，也可以用“撤销全部”回到解析前
- **尺度适用范围**：露点主要限制角色、服装、动作和身体细节；赛博城市、赛博朋克、镜头、光线、构图和画质等中性字段始终保留普通选项
- **角色预设**：按都市职业、礼服舞台、居家私房、双人关系和幻想概念分组，一次套用身份、造型、动作、场景与光线，套用后仍可逐项修改
- **内容尺度**五档（命令条上切换）：`日常` 负面词走模型默认；`暗示` / `私房` 依次启用更严格的负面词；`开放` 使用成人条目不包含露点；`露点` 只使用最高强度条目并自动套用高强基础值（只覆盖你没改过的字段）
- 顶部命令栏只保留一个「随机」按钮，按当前尺度和人物数量随机一套兼容的人物风格、预设造型和镜头方案；人物关系仍在角色步骤中调整
- 「画幅锁定」位于随机设置旁，可固定 16:9、9:16、1:1、4:5 等比例；锁定后自动匹配当前模型的像素尺寸，随机生成不会再把画幅改掉
- 「镜头方案」会一次性设置景别、身体焦点、机位、焦段、构图、景深和对应动作；顶部只做预览，点击「套用当前」后才统一应用
- 镜头方案新增脚部、足底、阴部、肛门和面部与下体同框等明确特写；阴部与肛门方案会自动切换兼容姿势和朝向，随后再套用镜头
- 顶部随机区域整合「人物风格」「预设造型」「套用方式」「镜头方案」「画幅锁定」「套用当前」和单一「随机」按钮
- 国际风格预设包含法式优雅、巴黎极简、复古老钱风、好莱坞华丽、意式华丽、北欧极简、Y2K 千禧风和哥特浪漫，不把“中国审美”错误地等同于古装
- 人物风格支持“整套造型 / 只应用妆发 / 只补未选择项 / 套用+随机”，并保留当前年龄、体型、姿势、场景、镜头、尺度和画幅
- 「套用+随机」为默认方式：点「套用当前」时保留当前已选和已改动字段，只对仍未确定的详细字段随机补全
- 露点档新增五维快捷区：表现强度、露出重点、17 套场景、10 套兼容姿势和成人道具；每个套餐会联动场景、光线、镜头、姿势、朝向和露出方式
- 露点场景同时提供常用方案卡和完整下拉列表；点击方案卡只更新待套用预览
- 露点快捷区支持“换姿势”“换镜头”“换道具”，局部替换只更新预览，最后统一点击“套用当前”
- 成人道具独立于普通配饰，包含避孕套、震动棒、按摩棒、跳蛋、假阳具、肛塞、串珠玩具、束缚带、眼罩、项圈、润滑液和按摩油等，并按挑逗、展示和高强互动过滤
- 成人道具会按当前露出重点过滤，例如后庭露出不会随机到仅适合胸部或阴部的主动使用道具
- 强度、姿势、镜头和道具使用兼容矩阵；最近 3–5 次选择会进入冷却，减少连续重复
- 固定项与随机生成项分开记录；第一次随机出的场景细节不会在第二次点击时被误当成用户固定项
- 无匹配的强度与露出重点组合会显示明确提示，并提供“查看全部”入口
- 填写 LoRA 触发词或启用本地 LoRA 后，露点方案卡会优先展示与该 LoRA 类型更匹配的场景，不显示 LoRA 文件名
- 镜头方案、露点套餐及其动作会作为整套锁定，不再被“其余随机”拆成镜头与姿势互相冲突的组合
- 尺度锁现在会阻止“套用当前”自动越级切换尺度；详细设置的单行工具条内也保留锁定/解锁按钮
- 详细设置改为单行紧凑工具条：内容尺度、当前预设摘要、展开预设、重置和快速/详细切换同排显示，参数表单整体上移
- 33 个人物风格分别拥有服装主色与材质差异，同组风格不再只更换脸和发型
- 人物风格已扩展到 33 个：新增甜心洋装、古灵精怪、清甜少女、冷感都市、韩系清透、运动元气、胶片复古、美式复古、港风大小姐、泰系轻混血、复古甜心、雨夜文艺
- 每种人物风格包含日常、透视、半裸和全裸搭配；其中半裸提供 5 套完整造型，名称直接写明内衣、睡袍、束腰、连体衣和袜装组合
- 半裸搭配会一次写入裸露区域、遮盖服装、材质、透明度、颜色、鞋履和可选袜类；切换套装时会清理上一套的袜装与配饰残留

- 所有下拉都可以**直接打字搜索**（支持中文标签和英文值），回车选中、↑↓ 切换、Esc 取消；选项按类别分组（服装：日常职业 / 礼服 / 泳装 / 内衣居家 / 袜装组合 / 日常性感……），开放选项收在「开放 · 18+」分组里，默认展开、点标题可收起

## 词库数据

所有选项、模型和预设都在 `data/prompts.js`，改词库不用动 `app.js`：

- `pair("中文", "English")`：中文用于界面显示，英文写入提示词
- `pair("中文", "English", { adultOnly: true })`：开放条目，界面上会打 `·AD` 标记并归到「开放 · 18+」分组
- `pair("中文", "English", { people: 2 })`：需要两个人的选项（成对角色、牵手、拥抱、亲吻、伴侣关系等）。主体选「单个人物」时这些选项不会出现；选「双人角色/小群像」时才会显示
- `pair("中文", "English", { relationships: ["mm", "ff"] })`：只给指定关系显示的选项；当前关系变化后会自动刷新动作和关系预设
- 页面启动时会做一次自检，重复选项、空标签、预设引用了不存在的值会打印到浏览器控制台（`[词库自检]`）

## 主体与字段适用性

字段显示哪一类主体，统一由 `app.js` 里的两张声明表决定，不再靠 CSS 类：

- `SUBJECT_GROUPS`：主体类型归到哪个分组（`person/couple/group → human`、`creature`、`object`）
- `FIELD_SUBJECT_GROUPS`：某个字段适用于哪些分组（没列出的字段对所有主体都显示）

要新增「动物 / 植物」这类主体，只要：在 `SUBJECT_GROUPS` 加一行、在 `FIELD_SUBJECT_GROUPS` 给专用字段加一行、在 `data/prompts.js` 补对应词库、在 `index.html` 加下拉。文本拼接函数里不再散落主体判断。

## 模型专属结构

- MiniMax H3 自动生成单一连续镜头、时间轴、机位和音频描述。
- H3/Wan 图生视频会省略重复的人物长相，重点描述动作和物理反馈。
- MOSS 编辑模式会生成保持身份、姿势、构图和背景的修改指令。
- Z-Image、Flux2、MOSS 使用自然语言结构。

## 数据与隐私

- 不发起任何 AI API 请求。
- 不加载 CDN、字体、统计脚本或远程图片。
- 自动保存、收藏和最近生成都存储在当前浏览器的本地存储中。
- 支持导出和导入收藏 JSON。

## 编码与模型语言

- HTML、JavaScript、CSS、Markdown 和启动脚本统一使用 UTF-8；页面本身不依赖远程字体。
- Z-Image 使用 Qwen3-4B 分词器，MOSS 使用 Qwen3.5-9B，MiniMax H3 使用 Qwen3-VL-32B 的 Qwen 分词器，Wan 使用 UMT5-XXL。
- 可用 ComfyUI 自带 Python 运行编码自检；它会检查项目文件、Qwen 分词器和 Wan 的 UMT5 中文往返解码：

```powershell
& "E:\Comfy-Desktop\ComfyUI-Installs\ComfyUI\standalone-env\python.exe" "D:\Codex\ComfyUI-Prompt-Studio\scripts\audit_text_encoding.py"
```

- “完成并检查”会识别替换字符、控制字符、残缺 Unicode 和常见 UTF-8/GBK 误码。
- 如果要求图片或视频直接生成可读文字，模型本身可能出现错字或乱码字形；这属于画面生成限制，不是网页编码问题。正式文字建议后期叠加。

## 说明

本页面负责参数化拼接提示词。AI 扩写、翻译和图片/视频反推仍由 ComfyUI Prompt Assistant 插件提供。

成年人相关选项仅用于明确成年、虚构、双方自愿角色。不得加入未成年人、真人身份仿冒、非自愿或暴力胁迫内容。

姿势分类参考了以下开源项目的公开维度，没有复制其代码或素材：

- [CMU OpenPose](https://github.com/CMU-Perceptual-Computing-Lab/openpose)：身体、手部、面部和足部关键点分类。
- [ComfyUI OpenPose Editor](https://github.com/space-nuko/ComfyUI-OpenPose-Editor)：身体朝向和四肢编辑方式。
