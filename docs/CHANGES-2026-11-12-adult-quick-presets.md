# 露点快速预设扩展（2026-11-12）

基线版本：`2026-11-12-reveal-workflow` / `20261112-151`

当前版本：`2026-11-12-director-final` / `20261112-181`

## 已实施

### 1. 五维露点快速预设

露点模式新增：

- 表现强度：全部、挑逗、明确展示、高强互动
- 露出重点：身体、胸部/乳头、阴部、肛门/后庭、腿袜、足部
- 17 套完整场景
- 10 套兼容姿势
- 成人道具
- 换姿势、换镜头、换道具、清除道具

所有控件只更新待套用预览，最终统一点击“套用当前”。

### 2. 成人道具

新增独立 `adultProp` 字段，不复用普通配饰或环境道具。

包含：

- 避孕套：未拆封、拆开包装、手持、双人使用
- 情趣玩具：震动棒、按摩棒、遥控跳蛋、吸吮玩具、假阳具、双头玩具、肛塞、串珠玩具
- 玩具状态：放置、手持、贴近身体、主动使用
- 束缚与氛围：软质束缚带、眼罩、项圈与牵引绳
- 辅助用品：润滑液、按摩油、毛巾

成人道具只在露点档显示，切换回低尺度时会自动清除，不残留到提示词。

### 3. 姿势兼容

增加 10 套姿势预设。每个姿势带有兼容的露出目标和四肢状态，局部换姿势只在当前露出重点允许的池中选择。

### 4. 镜头局部替换

“换镜头”根据当前露出重点循环兼容镜头，例如：

- 胸部：胸部特写、私房半身
- 阴部：阴部特写、面部与下体同框
- 肛门：肛门特写、面部与下体同框
- 腿袜：腿袜近景、电影全身
- 足部：脚部近景、足底特写

### 5. 人物关系快捷入口

已从页面、CSS 和 JS 中移除。关系仍可在角色设置中的“关系构成”调整。

### 6. 详细设置顶部压缩

- 详细设置改为单行工具条。
- 内容尺度改为紧凑下拉。
- 预设摘要、展开预设、重置、快速/详细标签同一行。
- 一句话输入、画幅锁定和简洁按钮在详细模式隐藏。
- 表单首卡顶部由约 346px 上移到约 285px（1600×1000）。
- 1366×768 下无横向溢出，顶部工具条仍保持一行。

### 7. 修复

- “套用+随机”不会再拆散所选镜头、姿势、朝向和露点动作。
- 已选详细字段会保留。
- 尺度锁会阻止自动越级到露点。
- 露点模式和详细设置刷新后可恢复强度、场景、姿势、道具、风格及服装。
- 成人道具选“不指定”时会正常清除旧道具。
- 修复“visible fabric texture”被误判为画面可读文字的检查误报。
- 修复从腿部镜头切换到跪姿时遗留旧腿部姿势的问题。
- 27 组露出重点与姿势组合逐项检查，未再出现语义冲突。

### 8. 第一阶段最终打磨

- 增加用户操作字段与随机生成字段的来源追踪，第二次“套用+随机”仍能持续变化。
- 随机结果增加短期冷却，场景、姿势和道具不会立即重复。
- 增加常用露点方案卡，点击卡片只更新预览。
- 无匹配组合显示原因，并提供“查看全部”恢复入口。
- 成人道具的 `targets` 元数据与当前露出重点联动。
- 表现强度同时过滤场景、姿势、镜头和成人道具。
- 详细设置单行工具条增加尺度锁按钮。
- 移除重复的“当前创作预设”大卡片。
- 增加淡入、卡片交错和按钮确认动效，并继续遵守 reduced-motion。
- 增加 Ctrl + Enter、Alt + R / P / C 快捷键。
- 顶部摘要显示本次“固定项 / 随机补全项”数量。
- LoRA 直出模式补齐成人道具输出，避免普通模式包含而直出模式遗漏。
