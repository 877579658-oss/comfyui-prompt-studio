# 露点工作流增强（2026-11-12）

基线：`2026-11-12-style-expansion` / 缓存版本 `20261112-142`

当前：`2026-11-12-reveal-workflow` / 缓存版本 `20261112-151`

## 本轮改动

### 1. 修复“套用+随机”破坏镜头联动

- 镜头方案及其姿势、动作、朝向、露出模式和露出动作作为整体保护。
- 用户已经修改过的详细字段会作为固定项保留。
- 随机补全结束后重新应用当前镜头方案，避免镜头、姿势和露出方式互相矛盾。

### 2. 尺度锁生效

- 锁定尺度后，“套用当前”不能再自动切换到露点。
- 需要越级套用时，必须先解锁。

### 3. 新增露点方案

- 露点尺度下显示独立快捷区。
- 支持 7 类露出重点：全部、身体线条、胸部/乳头、阴部、肛门/后庭、腿部/丝袜、足部。
- 内置 13 套完整场景方案，覆盖床边、镜前、落地窗、古风庭院、沙发、浴室、胸部、阴部、面体同框、后庭、腿袜和足部。
- 方案会联动场景、光线、氛围、视觉风格、镜头、姿势、朝向、露出模式、露出动作和身体焦点。
- “随机露点方案”只更新预览，点击“套用当前”后才写入。

### 4. 中性字段尺度规则

- 场景、时间、光线、氛围、表情、视觉风格和镜头等中性字段在成人档改为累计可选。
- 姿势、动作和露点行为仍按露点最高强度筛选。

### 5. 风格服装差异化

- 33 个人物风格通过 `STYLE_LOOK_ACCENTS` 拥有独立主色和材质。
- 同组风格继续共享五类搭配结构，但服装颜色和材质不再完全相同。
- “甜系洛丽塔”按用户要求保留名称。

### 6. 文案与布局

- 未选择风格时，摘要显示“尚未选择人物风格”，不再误报“已套用”。
- 短屏笔记本下取消整个顶部区域的长期吸顶，避免正文只剩很小空间。
- 刷新恢复时会保留保存前的风格、着装模式和预设服装，不再把“私房搭配”重置成“透视搭配”。

## 验证

- 33 × 5 = 165 套半裸搭配逐项套用通过，主色和材质均写入。
