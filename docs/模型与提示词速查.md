## 二、提示词公式

### 图像类（MOSS / Z-Image / FLUX）

```
[触发词], [主体: adult + 年龄 + 外貌], [服装/状态], [场景], [姿势], [景别+机位], [光线], [介质], [负面]
```

要点：短句、逗号分隔、可 tag 化；负面词固定一套。

### 视频类（Wan2.2）

```
[谁 + 在哪], [一个动作], [static camera + 景别], [光线], [画质]
```

要点：**5 秒只安排一个动作**；机位写死 `static camera`；不要多段动作或运镜。I2V 首帧已定人，**不要重复描述长相**。

### H3（MiniMax）

```
[镜头声明] + [主体 40 词] + [场景光线 35 词] + [动作段落 60–100 词] + [机位 20 词] + [音频线索 15 词] + [排除]
```

要点：英文散文、不分点、**≥150 词**（训练分布决定）。没有负面通道，排除项写正面句尾。

## 三、负面词库

**图像（MOSS / Z-Image）固定用：**

```
low quality, blurry, bad anatomy, extra fingers, extra limbs, deformed hands,
watermark, text, logo, oversharpened, overexposed, plastic skin
```

**Wan 视频**（模板自带中文负面可保留），可再加：

```
static, frozen, flicker, morphing, extra limbs, deformed hands, watermark, text
```

**H3**：无 negative 通道，写 `No text, no watermark, no cuts.`

| 能力 | 说明 |

## 五、排错

| 现象 | 多半是 |
| --- | --- |
| 画面不动或糊（Z-Image） | 检查 CFG 是否 1.0、步数是否 8 |
| 视频几乎静止（Wan） | 提示词没动作词，或 5 秒塞了多个动作 |
| H3 完全不听话 | 提示词太短（<120 词）或用了 tag 堆砌；漏了 `hmmotion` |
| H3 颗粒感 / 卡顿 | 换 seed，不要加强度（作者原话） |
| 视频没声音 | 检查音频 VAE 是否接到 CreateVideo |
| 人体崩 | 并列描述太多；降动作 LoRA 强度；负面加 `bad anatomy` |
