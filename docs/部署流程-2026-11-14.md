# 部署流程（2026-11-14 打通）

## 现状

- 本机原本**没有 git 二进制**，`D:\Codex\ComfyUI-Prompt-Studio\.git` 只是个数据目录，无法提交、推送、回滚。
- 2026-11-14 用 `winget install --id Git.Git -e` 装上 Git for Windows 2.56.0.4，位置 `C:\Program Files\Git\cmd\git.exe`（PATH 未自动生效时脚本会自己找）。
- 推送凭据由 **Git Credential Manager** 保存（`cmdkey /list` 里的 `git:https://github.com`），HTTPS 推送免交互即可通过，无需再配 token。

## 分支约定

| 分支 | 用途 | 备注 |
| --- | --- | --- |
| `master` | 源码主分支 | 本地开发，提交后推送 |
| `main` | **部署分支** | GitHub Pages 从 `main` 发布，只放要上线的产物 |
| `codex/apple-human-ux` | 旧功能分支 | 保留 |
| `backup/main-before-deploy-2026-11-13` | 历史备份 | **不要删除，不要 force push** |

`master` 与 `main` 的内容保持一致（历史 SHA 不同属正常，比对看树是否相同：`git diff --stat <main> master`）。

## 一键发布

```powershell
pwsh -File scripts\deploy-pages.ps1 -Message "feat: ..."          # 提交 + 推送 + 部署 + 校验
pwsh -File scripts\deploy-pages.ps1 -Message "..." -DryRun        # 只看将要做什么
```

脚本做的事：

1. `git add -A` + 提交（工作区干净则跳过）；
2. 推送当前分支到 origin；
3. 从 `origin/main` 派生一个临时分支，把源码分支的文件同步过去（含删除），单独提交一条 `deploy:`；
4. 推送到 `main`（快进，不改写历史）；
5. 轮询 `https://877579658-oss.github.io/comfyui-prompt-studio/`，比对 `index.html` 里 `app.js?v=` 的版本标记，确认线上已更新。

## 发布前必做

**改 `index.html` 的资源版本标记**，否则浏览器和 Pages CDN 会继续用旧 JS：

```html
<script src="./data/prompts.js?v=20261114-1"></script>
<script src="./app.js?v=20261114-1"></script>
```

当前版本：`20261114-1`（2026-11-14 露点方案扩容）。

## 回滚

```powershell
git log --oneline origin/main -5           # 找到上一个部署提交
git push origin <上一版 SHA>:main          # 需要时加 --force-with-lease
```

更稳妥的做法是在 `main` 上做 revert 提交，保留历史。

## 已知坑

- **PowerShell 改 HTML 会吃掉换行**：`Get-Content ... | Set-Content -NoNewline` 会把整份 index.html 压成一行。改 `index.html` 一律用 `edit` 工具，或先用 `[IO.File]::ReadAllText/WriteAllText`。
- **提交信息别用 `Set-Content -Encoding UTF8`**：会给首行加 BOM。用 `[IO.File]::WriteAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))`。
- `git commit -F` 前记得 `git add -A`，否则只提交了已暂存的部分。
- 仓库有 `core.autocrlf=true`，工作区 CRLF、仓库内 LF，`git add` 时会提示 "LF will be replaced by CRLF"，属正常。
- 仓库里原有的 46 个 `*.bak-*` / `pre-restore` 历史文件已在 2026-11-14 从版本库移除（归档在 `D:\Codex\ComfyUI-Prompt-Studio-archive\bak-20261114`），线上对应 URL 现在返回 404。
