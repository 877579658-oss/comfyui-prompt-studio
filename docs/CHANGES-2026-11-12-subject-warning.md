# 变更：一句话解析补充「主体未识别」提示

日期：2026-11-12（续 Codex 中断的验证工作）
文件：`app.js`（仅此一个文件；`index.html`、`server.js`、`data/prompts.js` 未改动）

## 背景

上一轮已经把解析入口改成「先预览、再应用、不随机补全」，但评审第 1 条的最后一句话没有落实：
**主体未识别时要明确提示，不能默默沿用默认人物。**

实测（第二条验收例）：输入「一位穿蓝色西装的成年男子站在办公室里，白天，全身照。」
只识别到「景别：全身」，主体仍是默认的「单个人物 · 成年女性」，界面仅有笼统的「未识别内容未写入」。
用户此时复制英文提示词，拿到的是一段描写女性的文本，与自己的描述不符。

## 改动

1. 新增 `SENTENCE_SUBJECT_FIELDS` 与 `sentenceSubjectWarning(items, source)`：
   当预览结果里没有任何主体/性别/年龄/物种/物体/自定义角色类字段命中时，返回一条明确警告，写明「当前仍沿用 `主体 · 呈现`」并指引手动修改。
2. `previewSentence()`：摘要追加「主体未识别，见下方提示。」，`#sentenceCoverage` 追加完整的 ⚠ 提示。
3. `applySentence()`：应用后摘要追加「主体仍未识别，见下方提示。」，并在 `#sentenceCoverage` 尚未包含该提示时补写一次。
