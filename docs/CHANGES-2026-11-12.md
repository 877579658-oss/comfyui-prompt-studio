## 3. 功能改动

### 3.1 「套用当前」= 套用已选项 + 其余随机

- 新增「套用范围」下拉（原"套用方式"），默认值 `random-rest`（套用+随机）
- `applyQuickSelection(modeOverride = null)`：点按钮时传 `"full"` 以外的当前模式
- 新增 `randomizeRemainingFields()`：对 `QUICK_FIXED_FIELDS` / `quickProtectedFields()` 之外的字段随机
- 保护字段：人物、年龄、风格、造型、镜头、尺度、画幅、人物关系、模型、语言等
- 套用后 toast 显示「已套用并随机 N 项（可撤销）」，`lastRandomState` 支持 ↺ 撤销
- 「换一套风格」按钮（原"随机"）只重抽顶层预设，调用 `applyQuickSelection("full")`

### 3.4 复制按钮修正

问题：主语言切成中文时，按钮标签互换，但旧逻辑按"英文/中文"取内容，导致「复制中文提示词」复制出英文。

修复（`app.js`）：

```js
$("copyPromptLarge").addEventListener("click", () =>
  copyText($("promptOutput").value, primaryLanguage === "zh" ? "中文提示词已复制" : "英文提示词已复制")
);
$("copyPromptZh").addEventListener("click", () =>
  copyText($("promptZhOutput").value, primaryLanguage === "zh" ? "英文提示词已复制" : "中文提示词已复制")
);
```

原则：**按钮复制它自己对应的文本框内容**，标签跟随 `primaryLanguage`。
